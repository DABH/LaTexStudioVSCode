How it works

The actual LaTeX toolchain is downloaded on demand so the extension stays tiny.

  1. 1

    Install the extension

    About 40 KB. Nothing else is downloaded yet.

  2. 2

    First build → one-time download

    You'll be prompted to download the Tectonic engine (~30 MB) for your OS. Stored inside the extension folder.

  3. 3

    First use of a LaTeX package → fetched from CTAN

    Tectonic grabs only what your document needs and caches it locally. No bulk install.

  4. 4

    Every subsequent build → fully offline

    Zero network access. Just fast, clean PDF compilation.

Behind a proxy or air-gapped? Set latexStudio.engine to xelatex, lualatex, or pdflatex to use a TeX distribution you already have installed — nothing extra gets downloaded.

Frequently asked questions

Do I need to install TeX Live or MiKTeX?

No. LaTeX Studio downloads a self-contained Tectonic engine on first use. If you'd rather use a TeX distribution you already have, set latexStudio.engine to xelatex, lualatex, or pdflatex.

How big is the first-run download?

About 30 MB for the Tectonic engine. After that, LaTeX packages your document references are fetched from CTAN on demand (typically a few MB total) and cached locally.

Does it work offline?

Yes — after the first build (which needs the engine) and the first use of any new package (which Tectonic fetches once). After that, builds are fully offline.

I'm behind a corporate proxy. What now?

Either configure a system proxy so Node/HTTPS can reach github.com and ctan.org, or use a local TeX distribution by changing the latexStudio.engine setting.

Can I open existing PDFs with it?

Yes. LaTeX Studio acts as a built-in PDF reader for VS Code. Click any .pdf file in the Explorer and it opens in the same PDF.js viewer used for compiled output.

Does it send any telemetry?

No. No telemetry, no accounts, no analytics. Your documents never leave your machine.

How do I uninstall cleanly?

Run LaTeX Studio: Reset Everything (Before Uninstall) from the Command Palette before uninstalling. That removes the downloaded engine and Tectonic's package cache (which VS Code doesn't clean automatically).

Is it open source?

Yes. The source lives on GitHub. Issues and contributions welcome.
